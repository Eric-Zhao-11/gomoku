# 五子棋 · 人机对战

一个用原生 HTML + CSS + JavaScript 写的五子棋小游戏,无需安装任何依赖。

🎮 **在线试玩**:https://eric-zhao-11.github.io/gomoku/

也可以下载后双击 `index.html` 在本地开玩。

这是我 GitHub 生涯的第一个仓库 🎉

## 玩法

- 你执**黑棋**先行,电脑执**白棋**,五子连珠即获胜
- 鼠标点击棋盘交叉点落子,悬停时有半透明预览
- 支持悔棋(一次撤回双方各一手)、电脑先手开局、重新开始
- 获胜时五连子会金色高亮,并有结算弹窗

## 电脑 AI

AI 采用**棋型评分**策略:对每个候选点,在四个方向上用字符串模式匹配识别棋型——

| 棋型 | 说明 | 分值 |
|------|------|------|
| 成五 | 五连 | 10,000,000 |
| 活四 | 两端开放的四连 | 500,000 |
| 冲四 / 跳冲四 | 再下一子即成五 | 120,000 |
| 活三 / 跳活三 | 两端开放的三连 | 45,000 ~ 50,000 |
| 眠三 | 一端被封的三连 | 5,000 |
| 活二 / 眠二 | 二连 | 100 ~ 1,000 |

最终按 `进攻分 + 防守分 × 0.9` 加权选择落点:自己能成五立即出手,对方要成五必然封堵,否则兼顾进攻与防守。会做双三、冲四杀棋,也会识破你的连子意图。
